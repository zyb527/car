# 跟随摄像头使用与标定

本目录是独立的 OpenART 双红外点识别程序，不会覆盖旧版摄像头代码。

## 文件

- `main.py`：烧录到 OpenART 后运行的入口。
- `config.py`：现场标定参数。
- `ir_tracker.py`：双点配对、单点退化、IPM、物理角度和三字段协议。

UART 输出协议：

```text
x_cm,y_cm,theta_deg
0
```

`x_cm,y_cm` 是像素 x 较大右灯经过 IPM 后的车体系物理坐标：第一维向右
为正，第二维向前为正。`theta_deg` 是两灯分别经过 IPM 后得到的物理灯线角
相对理想平行角的误差，因此两车平行时为 `0°`。`distance_px`、亮斑质量和
像素端点只在摄像头内部使用。

已经锁定双灯后若只剩一个有效亮点：`x<=150` 判为右灯并继续输出位置，
同时发送 `theta=0` 关闭视觉角速度修正；`x>=170` 判为左灯并立即输出丢失。
中间区域按上一帧端点连续性判断，无法确认则按丢失处理。未锁定双灯时不能
从单点直接建立目标。

## 烧录前注意

1. 将 `config.py`、`ir_tracker.py`、`main.py` 放在 OpenART 同一目录。
2. 首次标定保留 `DEBUG_DRAW=True`。
3. 默认参数只用于静态调试，不能直接当作比赛参数。
4. 完成标定后将 `DEBUG_DRAW=False`，减少绘图造成的帧率波动。
5. `DEBUG_PRINT=True` 时，OpenART USB 控制台每 200 ms 输出一次角度、中点、灯距和质量；它不使用跟随 UART。标定完成后关闭。

## 必须测量的参数

### 1. 画面方向

参数：

- `H_MIRROR`
- `V_FLIP`

测量方法：

1. 保持摄像头最终安装姿态。
2. 手动把红外灯向图像右侧移动，确认输出 `mid_x` 增大。
3. 手动把红外灯向图像下方移动，确认输出 `mid_y` 增大。
4. 如果方向相反，修改镜像或翻转参数后重新测量所有像素参考值。

### 2. 曝光和灰度阈值

参数：

- `EXPOSURE_US`
- `IR_THRESHOLD`
- `BLOB_PIXELS_MIN`
- `BLOB_AREA_MIN`

需要在比赛现场可能出现的最亮、最暗环境各测一次。

测量方法：

1. 关闭红外灯，使用 OpenART IDE 的灰度直方图/阈值工具记录 ROI 内背景最高灰度。
2. 打开红外灯，在最远合法距离记录较暗灯点的最低灰度。
3. `IR_THRESHOLD` 下限应高于背景最高值并留约 5～15 灰度余量，同时低于真实灯点最低值。
4. 调整 `EXPOSURE_US`，使两个灯点稳定可见，但不要形成大面积过曝白块。
5. 记录最远、最暗情况下每个真实灯点的最小 `pixels` 和包围框面积。
6. `BLOB_PIXELS_MIN`、`BLOB_AREA_MIN` 取真实最小值的约 50%～70%，同时必须高于现场噪点最大值。

如果背景最高灰度与灯点最低灰度没有稳定间隔，仅靠软件阈值不够，需要加窄带红外滤光片、遮光罩或提高红外灯与背景的亮度差。

### 3. ROI

参数：

- `ROI = (x, y, width, height)`

测量方法：

1. 两车分别放在所有允许的最近、最远、最前和最后相对位置。
2. 记录两个灯点出现过的最小/最大 x、y。
3. 四边各增加约 10～15 像素余量。
4. ROI 之外应尽量排除地面反光、顶灯和车体高亮部件。

### 4. 理想队形参考值

参数：

- `REF_CX`
- `REF_CY`
- `REF_LINE_ANGLE_DEG`
- `REF_DISTANCE_PX`
- `IPM_IMAGE_TO_PLANE`
- `REF_TARGET_X_CM`
- `REF_TARGET_Y_CM`
- `REF_PLANE_ANGLE_DEG`

测量方法：

1. 将两车摆成最终希望保持的理想并排、同向、平行队形。
2. 摄像头和红外灯必须使用最终安装高度与角度。
3. 静止采集至少 100 帧有效输出。
4. `REF_CX`、`REF_CY` 取中点坐标平均值。
5. `REF_DISTANCE_PX` 取两灯像素距离平均值。
6. `REF_LINE_ANGLE_DEG` 取连线角平均值。角度靠近 `90°/-90°` 时不能直接普通平均，应先把负角加 180°放到同一侧，再平均并归一化。
7. 用最终 `IPM_IMAGE_TO_PLANE` 分别投影两灯；右灯物理坐标均值写入
   `REF_TARGET_X_CM/REF_TARGET_Y_CM`，两物理点连线的周期角均值写入
   `REF_PLANE_ANGLE_DEG`。

### 5. 合法灯距范围

参数：

- `PAIR_DISTANCE_MIN_PX`
- `PAIR_DISTANCE_MAX_PX`

测量方法：

1. 在允许的最近车距记录 100 帧灯距范围。
2. 在允许的最远车距记录 100 帧灯距范围。
3. 最小值向下留约 5 像素或 10%余量，最大值向上留相同余量。
4. 余量不能大到把现场常见反光点组合包含进来。

### 6. 合法连线角范围

参数：

- `PAIR_ANGLE_TOLERANCE_DEG`

测量方法：

1. 在两车允许的最大相对角偏差下采集数据。
2. 计算每帧连线角与 `REF_LINE_ANGLE_DEG` 的无方向角误差。
3. 取最大正常误差再增加约 3°～5°余量。

### 7. 亮斑形状和大小对称性

参数：

- `BLOB_ASPECT_MIN`
- `BLOB_ASPECT_MAX`
- `PAIR_SIZE_RATIO_MIN`

测量方法：

1. 在最近、最远、最亮和最暗情况下记录真实灯点的宽、高和像素数。
2. 宽高比范围在真实最小/最大值外各留约 20%余量。
3. 每帧计算 `较小灯点pixels / 较大灯点pixels`。
4. `PAIR_SIZE_RATIO_MIN` 取正常数据最小值再减约 0.05～0.10，不建议低于 0.20。

### 8. 单帧最大跳变

参数：

- `MAX_MIDPOINT_JUMP_PX`
- `MAX_DISTANCE_JUMP_PX`
- `MAX_ANGLE_JUMP_DEG`

测量方法：

1. 让两车以计划中的最高速度完成前进、横移和转向。
2. 记录相邻有效帧的中点位移、灯距变化和角度变化。
3. 三个参数取对应正常最大值的约 1.5～2倍。
4. 用手电或反光物制造假亮斑，确认这些假目标跳变会超过门槛并被拒绝。

### 9. 滤波、确认和发送周期

参数：

- `EMA_ALPHA`
- `ACQUIRE_CONFIRM_FRAMES`
- `TX_MIN_INTERVAL_MS`
- `LOST_REPORT_INTERVAL_MS`

建议从以下值开始：

- `EMA_ALPHA=0.35`：增大响应更快但更抖，减小更平滑但延迟更大。
- `ACQUIRE_CONFIRM_FRAMES=2`：连续两帧才确认。
- `TX_MIN_INTERVAL_MS=30`：最大约 33 Hz。
- `LOST_REPORT_INTERVAL_MS=200`：丢失状态改变时仍会立即发送一次，之后每 200 ms 心跳。

## 上车前验证顺序

1. 静止双车：确认三字段约为 `REF_TARGET_X_CM,REF_TARGET_Y_CM,0`。
2. 遮住左灯并把右灯置于 `x<=150`：应继续输出位置且 `theta=0`。
3. 遮住右灯、只留左灯在 `x>=170`：应立即输出 `0`。
4. 加入手电、反光板和场地灯：不能把干扰亮斑组成目标对。
5. 手动移动两车：观察物理位置和角度连续，无突然跳变。
6. 架空车轮接入主控，检查目标出现/丢失时行为。
7. 空场最低速度落地，确认稳定后逐级提高速度。
