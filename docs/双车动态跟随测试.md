# 双车无线前馈动态跟随测试

本测试入口继续以 `car141929` 为运动基线。无线层只传递主车已经经过现有
S 曲线处理的 `(vx, vy, w)`。

后续已把 `car141929` 的 `approach`、`orbit` 完整控制逻辑迁入当前接口，
并按当前底盘比例换算线速度参数；最新参数与完整文件规划以
`完整双车跟随新方案.md` 为准。

## 烧录文件

主车烧录 `car/` 下：

```text
main.py
main_config.py
motor.py
odometry.py
wireless_feedforward.py
```

辅助车烧录 `car/辅助车/` 下：

```text
main.py
config.py
follow.py
motor.py
odometry.py
wireless_feedforward.py
```

跟随摄像头程序保持不变。

## 测试顺序

1. 两车按正常并排跟随姿态放置，留足前后、左右和旋转空间。
2. 先启动辅助车，确认视觉跟随进入 `TRACKING`。
3. 再启动主车；倒计时 3 秒后依次执行：
   前移、后移、右移、左移、顺时针、逆时针。
4. 每个动作运行 2 秒，并使用现有软停止停 1 秒后再进入下一动作。

测试速度直接复用 `NavigationConfig.PATH_SLOW_SPEED_CM_S`，旋转速度复用
`NavigationConfig.TURN_SLOW_W_RAD_S`。主车每 20 ms 发送一次
`MotorSystem.get_limited_command()`。

辅助车以无线前馈作为基础运动，并叠加视觉队形修正。视觉暂时丢失时继续
执行新鲜前馈；无线帧超过 300 ms 未更新会退回纯视觉修正。视觉与无线两路
同时不可用时立即硬停止。
