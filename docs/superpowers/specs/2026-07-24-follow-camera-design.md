# 跟随摄像头可靠双红外点识别设计

## 目标与边界

在 `car/跟随摄像头/` 中新建一套独立的 OpenART 跟随摄像头程序，不修改
`car_follow_last/followcam_ir/`。摄像头只负责：

1. 从 QVGA 灰度图像中识别主车上的两个指定红外灯点。
2. 输出中点、两点连线角、两点像素距离和质量值。
3. 在目标丢失时立即报告丢失，并持续发送低频丢失心跳。

不在摄像头端反解真实世界坐标，也不实现底盘控制。

## 兼容协议

UART 保持 115200 波特率和原六字段文本协议：

```text
1,mid_x,mid_y,line_angle_deg,distance_px,quality
0,0,0,0,0,0
```

`quality` 继续表示两个有效亮斑的像素数之和，并限制在 `0..999`，避免改变既有字段语义。

## 数据流

```text
灰度图像
  -> ROI 内亮斑检测
  -> 单个候选过滤
  -> 候选两两配对
  -> 几何与历史连续性评分
  -> 连续两帧确认
  -> 中点/距离/周期角 EMA 滤波
  -> 六字段 UART 帧
```

### 单个候选过滤

候选必须同时满足：

- 像素数和包围框面积达到下限。
- 宽高比位于配置范围内。
- 位于配置 ROI 内。

OpenART 的 `find_blobs()` 使用 `merge=False`，防止两个目标灯点被合并。

### 候选配对

不再直接选择最大的两个亮斑。对全部候选两两组合，先执行硬约束：

- 两点距离位于 `PAIR_DISTANCE_MIN_PX..PAIR_DISTANCE_MAX_PX`。
- 两点像素数比例不低于 `PAIR_SIZE_RATIO_MIN`。
- 中点、距离和角度相对上一有效帧的跳变量不超过配置上限。

通过硬约束的组合按以下误差加权评分，分数最低者胜出：

- 与参考灯距的误差。
- 与参考中点的误差。
- 两灯大小不对称误差。
- 与上一帧中点、距离和角度的连续性误差。

首次识别没有历史值时只使用参考值和对称性评分。

### 状态确认与滤波

- 新目标连续 `ACQUIRE_CONFIRM_FRAMES=2` 帧有效后才输出 `found=1`。
- 已确认目标出现无有效配对时，立即输出一次 `found=0`。
- 持续丢失期间每 `LOST_HEARTBEAT_MS=200` 发送一次丢失心跳。
- 中点和距离采用 EMA。
- 连线角以 180°为周期计算最短角误差后再做 EMA，避免 `89°/-89°` 附近跳变。

## 参数原则

所有现场相关值集中在 `config.py`：

- 图像方向、曝光时间、灰度阈值和 ROI。
- blob 像素/面积/宽高比范围。
- 参考中点、参考角度和参考灯距。
- 配对距离、面积比例与单帧最大跳变量。
- 获取确认帧数、滤波系数、发送周期和调试绘图开关。

默认值只用于首次低速调试，README 必须明确要求完成现场测量后再使用。

## 故障处理

- 找不到有效候选对时不得用任意两个亮斑凑数。
- 无效数值、零距离或异常角度不输出 found=1。
- UART 发送异常不改变跟踪状态；调试模式下用 LED/画面提示。
- 主循环捕获可恢复的单帧异常并发送丢失帧，避免旧目标数据长期保留。

## 测试

桌面测试覆盖纯算法：

1. 从多个亮斑中选择符合参考几何的目标对。
2. 拒绝距离、面积比例或形状不合理的组合。
3. 历史连续性优先于突然出现的大反光点。
4. 连续两帧后才确认目标。
5. 已确认目标丢失时立即进入 lost。
6. 中点和距离 EMA 正确。
7. 角度在 ±90°边界附近按 180°周期平滑。
8. 输出测量字段类型和范围保持协议兼容。

OpenART 端最后执行语法检查和架空车轮/静止双车的硬件验证。
