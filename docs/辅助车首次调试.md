# 辅助车纯视觉跟随：首次调试

## 烧录文件

只把 `car/辅助车/` 中以下五个文件放到主控板同一目录：

```text
main.py
config.py
follow.py
motor.py
odometry.py
```

`tests/` 和桌面生成的 `__pycache__/` 不烧录。跟随摄像头端继续使用
`car/跟随摄像头/` 中的独立程序。

## 上电前

1. 架空三个车轮。
2. 确认摄像头 TX 接主控 RX，并共地。
3. 确认主控摄像头端口是 `config.py` 中的 `UART_ID=5`。
4. 保持 `FRONT_KI / DISTANCE_KI / ANGLE_KI` 全部为 `0.0`。
5. 先完成电机、编码器和 IMU 方向检查，不能直接高速度落地。

## 首轮方向检查

每次只制造一个误差，并只修改 `config.py` 中对应的方向符号：

1. 改变主车相对辅助车的前后位置，确认 `VY_SIGN`。
2. 改变两车横向间距，确认 `VX_SIGN`。
3. 改变两车相对航向，确认 `W_SIGN`。

不要通过交换控制公式或临时修改 `follow.py` 修正方向。

## 参考队形

把两车摆成最终希望保持的左侧并排姿态，记录稳定摄像头输出的均值，并同步写入：

```text
REF_CX
REF_CY
REF_DISTANCE_PX
REF_LINE_ANGLE_DEG
```

`REF_CY` 第一版只用于有效性和调试，不直接控制底盘。

## 调参顺序

1. 保持三个 `ki=0`。
2. 分别从小到大调整 `FRONT_KP`、`DISTANCE_KP`、`ANGLE_KP`。
3. 调整三个死区，消除对齐后的来回抖动。
4. 再逐步提高 `MAX_VX / MAX_VY / MAX_W`。
5. 只有确认存在稳定残差时，才小幅增加对应 `ki`。

每次只改变一个通道，先架空，再空旷场地低速落地。

## 必测停车场景

以下场景在摄像头连续 `LOST_CONFIRM_FRAMES` 帧确认丢失后，必须进入 `LOST_STOP` 并清零 PWM：

- 遮住或关闭任意一个红外灯；
- 拔掉摄像头串口；
- 摄像头发送 `0,0,0,0,0,0`；
- 发送字段缺失、越界、`NaN/Inf` 或低质量帧；
- 人工中止 `main.py`；
- 主循环出现异常。

恢复目标后必须连续两个干净主循环收到有效测量，车辆才会重新进入
`TRACKING`。
